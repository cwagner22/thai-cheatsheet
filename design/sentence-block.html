Sentence block — three layouts, four states each

Each column is 620 px wide — the practice column on a 13" MacBook with the sentence rail open, where the current three-column layout squeezes the sentence into ~260 px and the count and the button collide with it. Long sentence (8 syllables) throughout; "Done" shows two misses highlighted.

A — Sentence full width, one action row under it

The sentence gets the whole column width (no side columns squeezing it). Under it one centred row: the status text on the left, the red button in the middle, key hints on the right. The count-in number appears in the empty space to the left of the sentence, so it sits right where you start reading. Closest to what you have, minus the collisions.
